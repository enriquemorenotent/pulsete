A local-first IRC desktop client. Your workspace stays alive.

Pulsete keeps networks, buffers, muted nicks, notes, and transcripts on your machine, so disconnects do not erase the working context around your conversations.

Built for IRC sessions that do not always stay connected.

Durable workspace

Saved networks, buffers, watchlist entries, muted nicks, and notes survive restarts.

Local-first history

SQLite transcripts remain readable even when the current socket is offline.

Offline-friendly UI

Disconnected networks stay visible, with channel and query logs still selectable.

Native package

GitHub Releases ship an Electron desktop app as a `.deb` for Ubuntu 24.04.

Install on Ubuntu

The current packaged desktop target is Ubuntu 24.04 on amd64. Installing the `.deb` also registers the Pulsete APT source and signing key. 

curl -L -o pulsete_0.1.3_amd64.deb \
  https://github.com/enriquemorenotent/pulsete/releases/download/v0.1.3/pulsete_0.1.3_amd64.deb
sudo apt install ./pulsete_0.1.3_amd64.deb

Future releases then arrive through the normal Ubuntu update flow: sudo apt update and sudo apt upgrade.
